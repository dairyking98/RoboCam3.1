Calibration

Teach RoboCam where every well physically is, from four corner positions. Required again whenever the plate is removed or reseated.

Workflow guide 1 · Setup 2 · Motion Profiles 3 · Calibration 4 · Experiment 5 · Manual Control 6 · Processing

How it works

RoboCam only needs the four physical corners of the plate. Every other well position is generated by bilinear interpolation across those four points, so the calibration is specific to this exact plate placement — reseat or swap the plate and it needs to be redone.

1. Set the four corners

Jog to each physical corner of the well plate using the movement pad (with a selectable step size) or "Go To Position", then click Set for Upper-Left, Lower-Left, Upper-Right, and Lower-Right. The well map auto-generates once all four are set.

2. Set the grid

Enter the grid dimensions (e.g., 12 × 8 for a 96-well plate) and pick a scan pattern — Raster or Snake — then click Update Well Map.

3. Save it

Update & Save… writes a calibration JSON to config/calibrations/, including the corners, dimensions, and pre-computed interpolated positions/labels for every well. Load… restores a previously saved file. The saved calibration is what you'll pick by name on the Experiment tab.

4. Spot-check with Quick Capture

Click any well on the map to jog there immediately. Quick Capture grabs a single still or a short raw burst right from this tab (written to outputs/quick_capture/) — use it to confirm focus and exposure on a couple of wells before committing to a full experiment run.

New plate, or the same plate taken off and put back on the stage? Recalibrate before running an experiment — a stale calibration will jog to the old, now-wrong physical positions.
